# wiki-query

wiki.toml에서 위키 위치와 원천·검토자를 확인하고, 해당 위키의 SCHEMA.md를 기준으로 작업한다. 경로 예시의 docs/wiki는 설정값으로 바꾼다.

결과는 근거 있는 답변이다. SCHEMA.md와 index를 읽고 관련 정식 페이지를 검색한다. 위키 갱신이나 전체 원천 조사를 답변의 선행 조건으로 삼지 않는다.

1. 관련 overview/question에서 source와 원문 인용으로 내려가 확인한다. 검토 초안은 정식 지식의 근거가 아니다. 검토 기록 자체를 물었다면 승인·미반영 상태를 구분해 보여준다.
2. 결론 → 근거 페이지 링크·원문 인용 → 불확실한 부분 순서로 답한다. 양립하지 않는 주장은 양쪽의 시점·조건·근거를 보여준다. 오래되거나 deprecated인 기록을 현재 사실로 사용하지 않는다.
3. 위키에 없으면 없다고 밝히고 범위 내 원문 후보를 찾아 경로와 ingest 제안을 덧붙인다. 확인되지 않은 내용을 채워 넣지 않는다.
4. 답변이 재사용할 비교·분석·판단 근거라면 questions/overviews 변경안을 [공통 형식](../wiki-review/references/workflow.md)으로 준비해 [wiki-review](../wiki-review/SKILL.md)에 넘긴다. 답변은 먼저 제공하고 파일링만 따로 판단받는다. 일회성 답은 저장하지 않는다.

전달 전 결론이 인용보다 강하지 않은지, 현재 사실과 제안·이력이 분리됐는지 확인한다. 파일링하지 않는 답에 쓰기·승인 절차를 붙이지 않는다. 파일링 초안은 review의 preview 검사를 받는다.
