# 가상 상점 위키 만들기

README 시작 프롬프트에서 프로젝트 이름을 “가상 상점”, 문서 폴더를 `examples/raw`로 지정한다. 첫 단계는 `returns.md`만 대상으로 명시한다. 프로젝트 이력·과거 세션·메모리는 없음으로 지정하고 현재 검토 대화만 승인 근거로 연결한다.

에이전트가 source와 관련 question을 만들고 원문 줄 인용·연결을 검토하면 변경안을 읽고 결정한다. 그 뒤 다음처럼 요청한다.

> examples/raw/policy-change.md를 위키에 반영할 변경안으로 만들어줘. 기존 정책과 달라지는 조건도 보여줘.

새 정책의 30일을 모든 주문에 적용하면 잘못된 해석이다. 주문 접수일에 따른 14일/30일 구분과 주문 제작 예외를 유지해야 한다. 시점·조건이 다른 두 정책을 무조건 모순으로 표시하지 않는다.

반영 후 질문:

> 1월에 접수한 주문과 2월에 접수한 주문의 반품 가능 기간은 각각 얼마야? 근거도 알려줘.

기대 답은 14일/30일과 예외 조건, 각 원문 인용이다. 실제 사용자 결정은 현재 대화에서 받아 기록한다. 테스트 코드의 가상 승인 메시지는 실행 검증용이며 실제 위키의 승인 근거로 재사용하지 않는다.
